# 웹 시안 상세 정의 (v5 시안 기준)

작성일: 2026-10-12 · 인터뷰로 정한 내용. 기획서 `01_기획서.md`와 함께 본다.

## 1. 탭 구성 (폰 화면 아래 탭 5개)
| 탭 | 내용 |
|---|---|
| **내 주변 (메인)** | 지도 + 아래 구인글 목록 |
| 말로 추천 | 지금 만들어 둔 화면. 조건을 말로 쓰면 Claude가 경기를 골라 줌 |
| 내 신청·일정 | 신청한 경기와 상태(신청 → 수락 대기 → 입금 안내 → 확정) |
| **모집하기 (주장·총무용)** | 구인글 등록과 신청자 관리 (아래 8번) |
| 내 정보·팀 | 내 프로필과 팀 프로필 |

## 2. 내 주변 (메인)
- **형태:** 위에 지도(핀), 아래에 구인글 목록.
- **위치:** 지금은 예시 위치로 보여 줌. 실제 서비스에서는 **위치기반 동의를 받아야 함**.
- **지도:** 시안에서는 실제 지도 타일을 쓸 수 없어 서울·인천을 단순화한 약식 지도에 핀을 찍음. 실제 서비스에서는 지도 서비스 연결.
- **필터:** 날짜·시간대(오늘/내일/주말, 퇴근 후 등) · 거리 반경 · 포지션
- **정렬:** 시작 시간 임박순이 기본

## 3. 구인글 카드·상세에 들어갈 정보
이미 있는 정보: 날짜·시간, 체육관, 지역·가까운 역, 실력, 참가비, 설명

추가할 정보:
- **현재 인원 현황:** 참가 n명 / 정원 m명, 남은 자리, 진행 막대. **필요 포지션별** 남은 자리(예: 가드 1, 센터 1)와 이미 온 게스트·팀원 목록
- **경기 방식:** 한 경기 시간·총 이용 시간, 분위기(가볍게 / 진지하게)
- **실내코트 시설:** 샤워실·탈의실, 주차, 바닥·냉난방·골대, 실제 사진 (시안에서는 사진 자리 표시)

## 4. 신청 흐름 (시안에서는 가짜로 한 바퀴)
상세 화면 "신청하기" → 신청 완료(수락 대기) → 주장·총무와 **앱 안 간단 메시지**로 연락(수락 여부는 주장·총무가 정함) → 수락됨 → 입금 안내(계좌·금액, 경기 1시간 전까지 취소 가능) → "내 신청·일정" 탭에서 상태 확인

## 5. 내 정보
- 확정: 키, 포지션
- 추가: 닉네임·사진, 농구 경력·실력 수준, 참석 이력·노쇼 기록
- 자주 가는 지역·이동수단은 넣지 않음 (위치기반으로 대신 처리)

## 6. 팀 프로필
- 팀 이름·로고·소개
- 주 활동 요일·시간·장소
- 팀 실력 수준·분위기
- 게스트 후기·진행 기록

## 7. 정리할 점
1. **(결정) 실력 수준 표시:** 내 정보의 경력·실력 수준은 자기 평가라 **참고용 표시**로 둠. 신청 수락 여부는 **주장·총무가 직접 판단**(신청 후 주장·총무와 연락을 주고받으며 진행하는 현재 방식 그대로).
2. **노쇼 기록 공개 범위:** 주장에게만 보이게 할지, 프로필에 공개할지
3. **후기 방식:** 게스트 후기를 누가 쓰고 누가 볼 수 있는지 (2단계 후보)
4. **필터 거리 기준:** 기획서의 "이동 30분"을 거리 반경(km)과 어떻게 함께 쓸지

## 8. 모집하기 탭 (주장·총무용)
**구인글 등록 항목**
- 날짜·시작 시간, **앱에 등록된 체육관 중에서 선택** (선택하면 지역·가까운 역·시설 정보가 자동으로 채워짐, 오늘 상황이 다르면 수정). 찾는 체육관이 없으면 등록 요청은 이후 단계.
- 인원: **정원(전체 인원, 4~20명)** 과 지금 확정된 인원을 직접 고르고, 모집 인원 = 정원 − 확정 인원. 필요한 포지션(가드·포워드·센터)의 합이 모집 인원과 같아야 저장됨
- 실력 수준·분위기(가볍게/진지하게), 참가비, 한 경기 시간·총 이용 시간
- 시설 정보(샤워실·탈의실·주차·바닥·냉난방·골대), 한마디
- 올리면 "내 주변"에 바로 나타나고 카드에 "우리 팀 글" 표시. 지난 시간·필요 인원 0명은 막음.

**팀 정식 등록 상태:** 팀원 n / 7명 진행 막대 표시 (첫 글은 바로 가능, 7일 안에 7명 등록). 시안에서는 예시 값.

**신청자 관리 (구인글 안에서 같이 처리)**
신청함 → 수락/거절 → 수락함·입금 대기 → **입금 확인** → 참가 확정 → 경기 후 **참석/노쇼** 체크. 남은 자리가 없으면 수락 불가, 수락 취소 가능. 노쇼면 참가비는 팀이 가져가고 기록이 남음. 신청자 카드에는 키·포지션·실력(참고용)·참석/노쇼 이력·신청 메시지.
구인글 내리기는 두 번 눌러 확인.

**시안의 한계:** 신청자는 예시 데이터, 신청자와의 메시지, 체육관 등록 요청, 사진·로고 올리기는 아직 없음.

## 9. v5 변경 (스포츠 앱 방향, 2026-10-13)
**디자인 방향:** 에너지 있는 스포츠 앱 느낌. 남색 헤더와 진한 주황 포인트, 굵은 숫자.

**구인글 카드:** 가장 크게 **시작 시간 + 남은 자리 수 배지**. 5시간 안에 시작하면 "n시간 n분 후 시작" 표시. 마감이면 회색 "마감" 배지.

**상세 화면**
- 상단 큰 헤더(시간, 체육관, 남은 자리)
- **지도에 체육관 위치**와 **길찾기·카카오맵에서 보기** 버튼 (카카오맵 링크)
- **신청 버튼은 화면 아래에 고정** (참가비, 남은 자리와 함께). 신청서를 쓸 때는 같은 자리에 "신청 보내기"
- 상세에서는 아래 탭을 숨김

**모집하기 (주장·총무용)**
- 신청 현황을 숫자(새 신청·입금 대기·확정·남은 자리)와 포지션별 현황(가드 1/2 등)으로 한눈에, 상태별 필터
- **수락하면 바로 정원에 반영.** 입금 대기 상태도 자리를 차지하고 "내 주변" 카드의 남은 자리도 즉시 줄어듦. 수락 취소하면 자리가 다시 열림
- 정원이 차면 안내 배너, 남은 신청자는 "정원 마감 · 대기"
- **복사해서 올리기:** 지난 글 설정을 그대로 가져오고 날짜를 1주 뒤로
- **글 수정:** 올린 글의 날짜·정원·인원·시설 등을 수정. 이미 수락·확정한 인원보다 모집 인원을 줄일 수 없음
- **주장·총무 공동 관리:** 같은 팀이 같은 날 같은 시간에 글을 하나만 올릴 수 있고(중복이면 기존 글 수정으로 안내), 둘이 같은 글을 같이 수정하며 "마지막 수정 총무 · 방금"처럼 표시. 시안에서는 역할 전환 버튼으로 확인

## 10. 아직 정하지 않은 것 (v5 기준)
- 실제 서비스에서 주장·총무 계정 연결과 팀 소속 확인 방식
- 같은 팀 글 중복 기준 (같은 날 같은 시간 vs 같은 날 하루 한 글)
- 체육관 등록 요청과 사진 올리기
