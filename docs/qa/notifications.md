# 알림 통합 검증

1. **주기**: 운영 Worker 설정은 매분 실행이다. 미결제 만료→테스트 승인 조회→누적 환불→알림 순서로 처리한다. 한 단계의 오류는 다른 단계 실행을 막지 않으며 비공개 실행 기록에는 단계·건수·성공/실패만 남긴다. 현재 시각은 DB 기준이다.
2. **반복**: 수락 후 최대 30분과 경기 시작 중 빠른 기한을 사용한다. 5분 반복은 각 구간 시작에 맞추며 지연된 tick은 최신 한 번만 처리한다. 결제 확인 중·완료·취소·만료·권한 회수 뒤 독촉은 억제한다.
3. **중요 안내**: 알림함은 공통 기록이다. 앱 endpoint 우선, 없으면 웹 하나만 선택한다. 카카오 알림톡은 업체·계약·템플릿 설정 전 `setup_required`이며 네트워크를 호출하지 않는다. 미설정을 발송 성공으로 보고하지 않는다.
4. **결과**: 제공자 접수·읽음·참가 확정은 각각 다르다. 응답 유실은 `unknown`이며 같은 milestone을 자동 재발송하지 않는다. 명확한 실패만 현재 상태와 기한을 다시 검사하여 제한적으로 재시도한다.
5. **실행**: `pnpm check`, `pnpm test:e2e`, `pnpm check:migrations`, `pnpm exec supabase test db`. 실제 제공자 수신·스토어 앱 전경/배경/종료는 키·기기·빌드 환경 준비 후 별도 확인한다. 이 문서는 실제 수신 완료를 뜻하지 않는다.

공식 근거: [Workers Cron](https://developers.cloudflare.com/workers/configuration/cron-triggers/), [제공자 준비와 검증](push-ports.md).
