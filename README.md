# 농구장 매칭 플랫폼

팀(주장·총무)이 게스트를 구하고, 개인이 내 이동수단으로 30분 안의 실내농구장 게스트 자리를 신청하는 서비스의 기획 문서와 웹 시안입니다. 서울·인천에서 시작합니다.

## 폴더
- `01_기획서.md` 한 장 기획서 (문제, 사용자, 범위, 결정된 것, 열린 질문, 경쟁 서비스)
- `02_인터뷰메모/`, `04_참고자료/` 메모 폴더
- `03_화면설계/` 화면 흐름, 시안 상세 정의
- `04_시안_카카오맵/` 폰 화면용 웹 시안 (`index.html` 한 파일, 순수 자바스크립트, 빌드 없음)

## 시안 실행
1. `04_시안_카카오맵/config.example.js` 를 복사해 `config.js` 로 만들고 카카오 JavaScript 키를 넣습니다. (키가 없으면 약식 지도로 동작)
2. 카카오 개발자 사이트의 앱에서 **카카오맵 사용 설정 ON**, **JavaScript SDK 도메인**에 `http://localhost:8000` 등록
3. `04_시안_카카오맵` 폴더에서 `python3 -m http.server 8000` (윈도우는 `python`) 실행 후 `http://localhost:8000` 접속
4. 폰에서 같은 와이파이로 볼 때는 PC의 IP 주소(`http://192.168.x.x:8000`)도 SDK 도메인에 등록

`config.js` 는 `.gitignore` 로 제외돼 git에 올라가지 않으므로, 새 컴퓨터에서는 1번을 다시 해야 합니다.

## 시안 구성 (5개 탭)
내 주변(지도+목록) · 말로 추천 · 내 신청 · 모집하기(주장·총무용) · 내 정보·팀. 구인글, 신청자, 팀 정보는 모두 예시 데이터이고 브라우저 localStorage에만 저장됩니다.

## 알아둘 점
- "말로 추천" 탭은 Claude 아티팩트 안에서만 동작합니다. 이 폴더의 로컬 실행에서는 "연결할 수 없다"고 표시됩니다. 실제로 쓰려면 Claude API를 중간 서버로 연결해야 합니다. (API 키를 앱 안에 넣지 않음, 비용 부담은 아직 보류)
- 아직 없는 것: 로그인, 서버 저장, 실제 알림, 사진·로고 올리기, 체육관 등록 요청, 신청자와의 메시지(모집하기 쪽)
